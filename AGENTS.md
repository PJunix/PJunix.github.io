# PJunix Site Notes

This repository is a lightweight, static GitHub Pages cybersecurity portfolio. Use semantic HTML, CSS, and minimal vanilla JavaScript; do not add frameworks without a clear maintenance reason. Preserve the restrained dark research-notebook visual language and responsive behavior.

Never invent achievements, certifications, findings, or personal contact details. Keep security content technically accurate, educational, and safe. Maintain accessible navigation, visible focus styles, meaningful headings, and reduced-motion support. Test relative links and asset paths after every change, and keep the site free of secrets and unnecessary dependencies.
